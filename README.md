# Analyzing and Predicting Public Support for Title IX

## Project Overview
This project analyzes public attitudes toward Title IX using national survey data from the Marist Center for Sports Communication. The project was completed under a simulated scenario in which a university research lab received a grant to study public support for Title IX and identify groups that could benefit from targeted education and outreach.

Using Python, I examined how support for Title IX varies across demographic, political, and sports-related characteristics and developed a predictive model to classify respondents based on their likelihood of supporting Title IX.

## Methods
The analysis includes:
- Data cleaning and preparation
- Exploratory data analysis and visualization
- Bootstrap confidence intervals
- K-Nearest Neighbors (KNN) classification
- Train/test model evaluation
- Classification threshold comparison
- Accuracy, precision, recall, and F1 evaluation
- Confusion matrix analysis

## Tools
- Python
- Jupyter Notebook
- NumPy
- Data Science library
- Scikit-learn
- Matplotlib

## Data
The analysis uses a June 2022 national survey conducted by the Marist Center for Sports Communication with 573 adult respondents.

The complete Jupyter Notebook in this repository contains the Python code, visualizations, statistical analysis, predictive modeling, and interpretation of the results.
